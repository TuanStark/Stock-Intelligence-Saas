# Stock Intelligence SaaS — Complete Engineering Blueprint

**Version:** v1.0
**Perspective:** Senior Software Engineer / Product Architect (10+ years)
**Goal:** End-to-end production blueprint for building a Stock Intelligence SaaS, covering product, architecture, UX, UI, FE, BE, infra, and execution.

---

# 1. Executive Summary

This is not a stock chart website.

This is a **Stock Intelligence SaaS** designed to help investors make faster, clearer, and more confident decisions through:

* clean market data
* precomputed signals
* explainable insights
* AI summaries
* portfolio intelligence
* watchlists and alerts

The product does not sell charts.

It sells:

* faster decisions
* clearer signals
* confidence
* reduced analysis time

Charts are interface.
Insights are product.

# 10. Backend Engineering Specs

## Execution Layers

```text
API Layer
Application Layer
Domain Layer
Infrastructure Layer
Async Layer
```

## Request Lifecycle

```text
HTTP Request
  ↓
Controller
  ↓
DTO Validation
  ↓
Auth / Policy Guard
  ↓
Application Service
  ↓
Domain Rules
  ↓
Repository / Cache
  ↓
Response Mapper
  ↓
HTTP Response
```

## Async Lifecycle

```text
Event Published
  ↓
Queue
  ↓
Worker Consumer
  ↓
Idempotency Check
  ↓
Processor
  ↓
Side Effect
  ↓
Persist Result
  ↓
Ack / Retry / DLQ
```

## Non-Negotiable Rules

* no compute in request path
* no business logic in controllers
* no provider calls in transactions
* no non-idempotent workers
* no cache as source of truth
